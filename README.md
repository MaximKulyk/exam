# Test 13: Iterator Pattern

## Описание работы (Description)
Паттерн Итератор (Iterator) — это поведенческий паттерн проектирования, который позволяет последовательно обходить элементы составных объектов, не раскрывая их внутреннего представления.

В данном решении реализована коллекция `WordsCollection`, которая инкапсулирует массив строк. Для обхода этой коллекции реализован `AlphabeticalOrderIterator`, который реализует интерфейс `IIterator` и поддерживает два режима:
1. Прямой обход (от первого элемента к последнему).
2. Обратный обход (от последнего элемента к первому).

Клиентский код может получать итераторы из коллекции и обходить её элементы, не зная, как именно они хранятся внутри (в массиве, списке или дереве).
